This page runs patchwork in your browser: [Pyodide](https://pyodide.org) is Python compiled to
WebAssembly, so nothing is sent to a server. Pick the charges and the refinement criterion and
the hierarchy is built again: starting from a 16 × 16 base, the cells across which the charge
density changes by more than the threshold are tagged and covered with finer patches, one level
per regrid, and the potential of the charges in a grounded box is solved on the nodes of all the
levels together.

Each charge is a Gaussian of unit charge. A narrower charge or a lower threshold asks for more
levels; a shorter longest side splits the levels into more, smaller patches, which cover the
tagged cells more tightly. The unknowns are the free nodes of the composite solve, against those
of a uniform mesh as fine as the finest level. The same calls in a script:

```python
import numpy as np

from patchwork import AMRHierarchy, NodalPoisson, gradient_tags


def deposit(mesh):
    """A Gaussian charge at (0.5, 0.5), set on every patch."""
    for patch in mesh.local_patches:
        x, y = patch.local_node_coordinates(mesh, "rho")
        r2 = (x - 0.5) ** 2 + (y - 0.5) ** 2
        patch.field("rho").local[...] = np.exp(-r2 / 0.002) / (np.pi * 0.002)


mesh = AMRHierarchy(base_shape=(16, 16))
mesh.allocate_field("rho", centering="node")
deposit(mesh)
for _ in range(4):  # one more level per regrid
    mesh = mesh.regrid(gradient_tags(mesh, "rho", 10.0), max_patch_size=32)
    deposit(mesh)
solver = NodalPoisson(mesh)  # -∇²φ = ρ, grounded faces
solver.solve("rho", potential="phi")  # the potential, also on every patch as "phi"
```

In the browser the kernels run as NumPy instead of the compiled Pyccel loops, and the sparse
factorization is SciPy's, so the timings are slower than on your machine. The page installs the
patchwork wheel built with the site, and its dependencies, the first time it is opened; the
browser keeps them afterwards.
