## What is included

- **Nested patches.** Build aligned 1D or 2D refinement levels from half-open cell boxes.
- **mpiarray fields.** Allocate cell-centered patch fields with halo storage. The same API works in serial without MPI.
- **Patch plots.** Plot the active grid at each level or color patches by a field.
- **Small starting scope.** Includes a composite finite-volume Poisson solve; particle coupling and dynamic regridding are next.
