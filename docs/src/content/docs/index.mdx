## What is included

<CardGrid>
	<Card title="Nested patches" icon="open-book">
		Build aligned 1D or 2D refinement levels from half-open cell boxes.
	</Card>
	<Card title="mpiarray fields" icon="rocket">
		Allocate cell-centered patch fields with halo storage. The same API works in serial without MPI.
	</Card>
	<Card title="Patch plots" icon="document">
		Plot the active grid at each level or color patches by a field.
	</Card>
	<Card title="Small starting scope" icon="setting">
		Includes a composite finite-volume Poisson solve; particle coupling and dynamic regridding are next.
	</Card>
</CardGrid>
